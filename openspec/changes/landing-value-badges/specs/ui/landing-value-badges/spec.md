# Spec Delta

## Purpose

Adds quick-scan trust signal badges below the hero section to communicate credibility and reduce bounce.

## ADDED Requirements

### Requirement: Landing page displays value proposition badges

The landing page SHALL display a row of 4 value proposition badges below the hero section.

#### Scenario: User lands on the page

- **WHEN** a user views the landing page
- **THEN** they see a compact row of trust badges below the hero with icons and short labels
- **AND** badges communicate ISA certification, student count, Google rating, and location recognition

### Requirement: Badges are bilingual

Badge labels SHALL switch language with the page language.
