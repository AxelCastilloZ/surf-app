# Spec Delta

## Purpose

Balances the landing page's cool ocean palette with warmer coral and sand accents to create an inviting, tropical feel appropriate for a Costa Rica surf school.

## ADDED Requirements

### Requirement: Section headings use coral accent decoration
Section headings on the landing page SHALL include a small coral-colored decorative element to add visual warmth.

#### Scenario: User sees accented headings
- **WHEN** a user views any section heading on the landing page
- **THEN** the heading includes a coral-colored accent element (bar or subtitle) that distinguishes it from plain text

### Requirement: Alternating section backgrounds have visible contrast
Alternating sections SHALL use a background tone warm enough to be visibly distinct from white sections.

#### Scenario: User scrolls through sections
- **WHEN** a user scrolls through the landing page
- **THEN** alternating sections have a noticeably different warm-tinted background

### Requirement: Service card icons use warm tones
Service card icon containers SHALL use warm sand/coral tones instead of cool ocean tones.

#### Scenario: User views service cards
- **WHEN** a user views the services section
- **THEN** service card icon backgrounds use sand or warm tones instead of ocean-blue
